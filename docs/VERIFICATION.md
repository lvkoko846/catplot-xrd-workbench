### 浏览器（tests/browser-batch.mjs 11/11）
面板可用与范围声明、全选 6、批量全成功+汇总 6 行、峰位趋势 6 点折线、FWHM 单调、晶粒尺寸递减+表观警示、
失败样品原因入表、四类导出触发、390px 无溢出、零控制台错误。截图 scripts/shots/batch-trend.png。

### 关键修复：跨平台浮点鲁棒性
LM 优化器在噪声数据的病态边缘对浮点舍入敏感——同一初值在 Node 收敛、在 Chrome 触发法矩阵奇异
（两引擎 Math.exp/sin 末位差异）。修复：批量 auto 模式按 FWHM 初值倍数 [1, 1.8, 0.6, 2.6] 确定性多初值重试，
任一次收敛即成功，全部失败才报具体原因；固定初值模式尊重用户设置不重试。修复后 Node 与浏览器均 6/6 成功。
此修复提升对真实噪声数据的鲁棒性，非放宽断言。

## 十、未完成与局限
- 示例卡仅 3 张（2 计算+1 实验混合物），覆盖有限；无全库检索/匹配/元素筛选（按需求剥离）。
- 计算图谱无温度因子/仪器宽化/择优取向；实验示例 hkl 未指认、波长为推断。

- Scherrer 表观值需仪器宽化才可扣；忽略应变宽化；不与 TEM 粒径等价。
- 浏览器 Worker 堆内存未单列实测（Node 真值进程已测）。
- 批量趋势为单锚点贪心对齐（容差内最近匹配），峰位漂移超过容差的样品会漏配；需按体系调容差。批量不做物相定量；晶粒尺寸同 Scherrer 表观值局限。
- 公开部署与公开仓库为本轮交付目标（Sites 静态 + git bundle），发布许可以平台确认流程为准。
