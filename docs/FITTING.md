# 峰拟合技术说明（fit-1，公开版）

纯 JS 零依赖实现（`web/js/fitcore.js`），浏览器 Worker 执行（`web/js/fitworker.js`），Node 可直接 require 做真值测试。
**不做**：全谱 Rietveld 精修、物相定量（RIR/内标法）、峰面积→物相质量分数、结构精修。界面与导出均声明。

## 峰型公式（u = (x−c)/w，w = FWHM）
- Gaussian：`h·exp(−4ln2·u²)`；面积 `h·w·√(π/(4ln2))`
- Lorentzian：`h/(1+4u²)`；面积 `h·w·π/2`
- Pseudo-Voigt：`η·L + (1−η)·G`（η∈[0,1]）；面积按 η 线性组合
- Pearson VII：`h·(1+4u²·(2^(1/m)−1))^(−m)`（m∈[0.5,50]）；面积 `h·w·√(π/q)·Γ(m−0.5)/Γ(m)`，q=2^(1/m)−1
- 背景：无 / 线性 / 多项式 2–3 阶（以区间中点归一化 t=(x−mid)/half 改善条件数）/ 手动锚点折线（锚点固定，不参与优化）

## 优化器
Levenberg–Marquardt，解析 Jacobian（各峰型对 c/w/h/η或m 的闭式导数 + 背景幂次导数）。
参数缩放：c→1°、w→max(w₀,2·步长)、h→max(h₀,5%·ymax,1)、η→0.1、m→0.5、背景系数→ymax；在缩放空间求解 (JᵀJ+λ·diag)δ=Jᵀr。
约束（投影裁剪）：中心∈区间、FWHM>数据步长、峰高≥0、η∈[0,1]、m∈[0.5,50]；每参数可锁定。
收敛双阈值：相对代价变化<1e-9 且**实际**步长<1e-7；另设机器精度下限（RMS<1e-8·ymax）避免浮点噪声误判不收敛。
规模控制：优化用分层抽样≤6000 点；Rwp/Rp/残差在全区间点计算；单区间≤30 峰、自由参数>点数/3 判欠定。
取消：Worker 消息置标志（每迭代检查）+ 主线程 1.5s terminate 兜底 → ≤2s 终态。

## 失败原因（具体、不静默）
`bad-init`（区间/步长/非负/η/m/中心越界，逐峰指出）、`underdetermined`（自由参数 vs 点数）、
`not-converged`（迭代数+相对代价变化+最终代价）、`ill-conditioned`（法矩阵奇异/步长连续被拒）、
`strong-correlation`（指出哪两峰、相关系数 r>0.999）、`degenerate-peaks`（指出零高峰编号）、`cancelled`、`worker-error`。

## 质量指标（权重均匀 w=1）
- Rwp = √( Σ(y−f)² / Σy² )
- Rp = Σ|y−f| / Σ|y|
- χ²(red) = Σ(y−f)² / (N−P)，N=区间点数、P=自由参数数
- 参数标准误 = √(diag((JᵀJ)⁻¹)·χ²red)·缩放 —— **线性近似**，界面注明。

## Scherrer 表观晶粒尺寸
D = K·λ / (β·cosθ)，K 默认 0.89 可调；β 单位弧度换算。
仪器宽化三模式：未提供 → **表观值，未扣除仪器宽化，系统性偏小**（强制警示，不给无警示 nm 数）；
直接填仪器 FWHM → β=√(FWHM²−inst²)（Gauss 假设）；标样谱（LaB6/Si）→ 逐峰拟合得 FWHM(2θ) 曲线线性插值。
仪器宽化≥实测 FWHM 时报错。适用边界：约 1–100 nm；忽略应变宽化；**不与 TEM 粒径等价**。

## 卡片峰表对照口径
拟合峰中心 → 实验波长换算 d；与参考轨道最近示例卡峰比：Δd 恒给；Δ2θ 仅当参考波长=实验波长，
否则只给 d 偏差并声明"角度不可直接比"。参考值为公开示例卡峰位（CC0 计算 / MIT 实验），非实测；计算图谱无温度因子/仪器宽化。

## 存档（项目 v4）
fit = { regions[≤8]: {min,max,bg{model,coeffs,anchors},shape,peaks[≤30]{c,w,h,sp,locks},result{params,se,quality,iterations}}, instrument{mode,fwhm,std}, K, dbVersion, at }。

## 实测（2026-11-17，tests/fit-model.mjs / browser-fit.mjs）
- 单 pV 无噪声：中心/FWHM/面积误差 0（机器精度）；双峰重叠(间距=1×FWHM)：误差 0；
- SNR≈20：中心误差 0.0008°、FWHM 误差 1.54%、Rwp 0.127；倾斜背景+3峰：背景系数 [50,30] 精确恢复、Rwp 0；
- 30 峰×20001 点：1049ms（4 次迭代）<2s 目标；取消 ≤2s（实测 ~216ms）；
- XRED 真实谱三主峰：拟合中心 25.266/27.402/48.031°，与溯源文件数值偏差 0.046/0.018/0.009°，FWHM 0.4046/0.2678/0.4732°，Rwp 0.0429/0.1108/0.0802（不做含量推断）。
